# GroupSpend Web

Shared expense manager for students, friends and roommates: record expenses, split them, see who owes whom, and settle up. Web version of the GroupSpend Android app.

## Quick start
```bash
bash scripts/setup.sh        # installs deps, creates .env
cd backend && npm run dev    # http://localhost:5000
cd frontend && npm run dev   # http://localhost:5173
```
